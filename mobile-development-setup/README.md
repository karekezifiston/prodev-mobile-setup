#### Installation Steps

1. **Downloaded Expo Go**
   - Opened App Store (iOS) / Play Store (Android)
   - Searched for "Expo Go"
   - Clicked Install/Get

2. **Account Setup**
   - Opened Expo Go app
   - Created new account with email
   - Verified email address

3. **Testing Connection**
   - Ensured device and computer are on same WiFi network
   - Ready to scan QR codes for development

### Challenges Faced

#### Challenge 1: Network Connection
- **Issue**: Device couldn't connect to development server
- **Solution**: Ensured both phone and computer on same WiFi network

#### Challenge 2: Firewall Settings
- **Issue**: Firewall blocking Expo connection
- **Solution**: Allowed Expo through firewall settings

### Why Expo Go?

Expo Go provides several advantages:
- **Cost-effective**: No need for expensive emulators or multiple devices
- **Real device testing**: Test on actual hardware for accurate performance
- **Cross-platform**: Works on both iOS and Android
- **Live reloading**: See changes instantly
- **Easy sharing**: Share apps via QR code
